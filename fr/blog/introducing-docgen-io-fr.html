Présentation de docgen.io - La génération de pdf en tant que service

Il existe d’innombrables solutions qui tentent de transformer html / css en fichiers PDF générés. J’ai passé d’innombrables heures à essayer de donner aux documents générés une apparence parfaite. Parfois, les résultats de ces outils ont même été différents d’une machine à l’autre.

J’ai donc trouvé une alternative. Au lieu d’utiliser html / css, j’utilise le système de production de documents Tex (cliquez ici pour plus d’informations sur Tex).

Ajoutez-le à des modèles du moteur de templates, Mustache, et vous avez produit vous-même un système capable d’automatiser la génération de n’importe quel type de pdf: lettres d’information, factures, factures, contrats complexes … même des ebooks en filigrane - les possibilités sont infinies.

Consultez le site Web https://www.docgen.io/
