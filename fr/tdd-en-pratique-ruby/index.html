Le TDD en pratique avec Ruby

Une démonstration de refactoring en Ruby guidée par les tests, pour faire évoluer le code par petites étapes en conservant son comportement.

Ce que montre la démonstration

  • Partir d’un code existant et vérifier que ses tests passent avant de le modifier.
  • Réorganiser les responsabilités entre plusieurs classes sans changer le comportement attendu.
  • Utiliser les tests comme une boucle de retour rapide pendant le refactoring et les évolutions du code.
